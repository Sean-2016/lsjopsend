## 1. 端范围

这是本期的硬边界，优先于后面的字段说明。

| 端 | 本期 |
| --- | --- |
| Android | 适配。按保存字段调用对应 Flutter Widget 的 `fromSlot` |
| iOS | 适配。与 Android 使用同一份配置和同一套 Widget 参数 |
| H5 | 适配。读取同一份配置，按同一字段实现等价布局。不另做一套运营字段 |
| Web 桌面端 | **不适配。** 不读取、不渲染这五个内嵌广告组件，不为本期改 Web 广告位 |

运营后台本身是配置台，不区分端。运营保存的是一份配置。只有 Android、iOS、H5 在频道页消费它。Web 即使打开同一频道，也不展示这些组件，也不因这份配置多请求广告。

H5 不嵌入 Flutter Widget。H5 按第 7 节的字段自己排版，行为与 SDK 默认 UI 对齐：条数取返回素材和 `maxCount` 的较小值，隐藏字段不生效，关闭和角标规则与 SDK 一致。

## 2. 范围

### 2.1 本期交付（P0）

在底部导航的产品页面里，运营把广告组件拖进当前频道，填写广告位标识和该组件自己的字段，保存后由 Android、iOS、H5 渲染。

广告组件分类下五个组件：

| 组件名称 | 保存类型 `componentType` | 端上 Widget |
| --- | --- | --- |
| Banner 广告 | `bannerAd` | `BannerAdWidget.fromSlot` |
| 图标广告 | `iconAd` | `IconAdWidget.fromSlot` |
| 文字广告 | `textAd` | `TextAdWidget.fromSlot` |
| MREC 广告 | `mrecAd` | `MrecAdWidget.fromSlot` |
| 原生广告 | `nativeAd` | `NativeAdCard.fromSlot` |

相对旧表单：去掉轮播个数、轮播停留秒数、1 到 5 个展示位、必填的 700×400 尺寸枚举。新增 MREC 广告和原生广告。

### 2.2 不在本期

- Web 桌面端的内嵌广告渲染，以及为 Web 单独做的广告字段。
- 开屏 `SplashAd`、弹窗、贴片、盲点、悬浮。它们不是这五个内嵌 Widget。
- 信息流「每 N 条内容插一条」。那是列表插帧，不是原生广告组件。
- 金刚组件、活动组件、底部导航入口本身的名称和图标规则。本文只写广告组件。
- 广告平台里的广告位创建、素材审核、`display_rule` 配置。后台组件只填写已有广告位标识。
- `fromAd` / `fromAds`、自定义 `builder`、运营选择角标明暗、关闭按钮样式、轮播间隔、跑马灯速度。

### 2.3 约束

- 页面上的位置由组件在频道里的拖放顺序决定，不另填 Banner `placement`。
- 素材由广告位返回。组件不上传图片、不写标题文案。
- 实际展示条数取「广告位返回条数」和「最多展示条数」中更小的一个。返回 2 条时，上限写成 10 也只展示 2 条。`maxCount = 0` 表示不截断。
- 隐藏字段不传给端上。切换布局后，被隐藏字段里的旧值作废。
- 广告位标识原样保存、原样下发。不去掉中间空格以外的字符，不改大小写，不换成别的编码。只去掉首尾空格。

## 4. 后台交互

入口：大前端配置 / 底部导航管理。广告组件只出现在「配置类型 = 产品页面」的频道画板里。功能页面没有画板，也不能在这里拖广告组件。

画板分三块，同时可见：

| 区域 | 内容 |
| --- | --- |
| 左：组件模板 | 广告组件、金刚组件、活动组件。广告组件五个卡片两列排布 |
| 中：手机预览 | 搜索条、频道名、已拖入的组件。搜索条和频道名是壳，不是可配置组件 |
| 右：并排两列 | 左列「切换频道」，右列「组件模块内容配置」 |

组件挂在频道上，不挂在导航入口上。入口 A 的 Hot 和入口 B 的 Hot 各有自己的组件列表。

### 4.1 拖入

左侧卡片可以拖，单击不会放进画布。说明文案是「点击选择下方模块，拖动至中间预览页面中」。

1. 按住卡片拖动。卡片变淡。拖到手机预览上时，手机外框出现虚线。拖出预览后虚线消失。
2. 在手机预览内松开，包括落在搜索条或频道名上。当前频道末尾新增一个组件实例，并立刻选中它。
3. 拖的是模板，不是把卡片从左侧移走。同一类可以反复拖入，每次都是新实例，互不影响。
4. 频道里还没有组件时，预览区显示「从左侧把组件拖到这里」。放进第一个组件后，这句话消失。
5. 本期不能在画布里拖动改顺序，也不能插到两个组件中间。新组件总在该频道最后。删除某个组件后，它后面的组件依次上移。

拖入后该实例使用第 6 节的默认值，广告位标识为空。页面变为未保存，发布按钮不可用。

### 4.2 选中和配置

点预览里的某个组件，它出现蓝色描边，右侧打开这一份实例的表单。表单标题是组件名称，例如「图标广告」。左侧模板里，与这个组件同类的卡片同时出现蓝框。两个 Banner 都在画布上时，选中哪一个，左侧都是同一张 Banner 卡片亮起；表单只改当前这一份。

没有选中组件时，右列是空状态「请先点击画布内组件」，不显示字段。

表单最下方是「从画布移除」。只删除当前这一份，不弹确认。删完后取消选中。该频道没有组件时，重新显示拖入提示。

改字段的即时反馈：

| 操作 | 页面怎么变 |
| --- | --- |
| 改广告位标识、宽度、条数、列数、间距等文本 | 光标留在输入框。非数字会被去掉。图标广告的预览按新数字重排，其他组件的预览不按条数重排 |
| 改单选，例如布局、广告形式 | 整页刷新。该布局不该出现的字段立刻隐藏。图标广告改成大或普通 Banner 时，预览高度跟着变 |
| 图标广告「最多展示条数」在非宫格下选「指定条数」 | 下面出现「条数」输入框。改回「不限制」后输入框消失 |
| 图标广告布局改成宫格 | 「最多展示条数」变成必填数字框，没有「不限制」，下面显示「最大值不要超过列数*3」 |
| 悬停图标广告的某个布局选项 | 选项上方出现黑色气泡，文案见第 6.2 节。移开或滚动配置区后气泡消失。文字广告没有气泡 |

隐藏字段里原先填过的值，在再次切回该布局之前仍留在草稿里，保存时按第 6 节丢掉，不传给端上。

### 4.3 切换频道和入口

切换频道有两处，效果相同：编辑频道栏的「当前频道」下拉，或右侧「切换频道」列表。当前频道是浅蓝底。

切换后：

- 中间预览换成该频道自己的组件。
- 取消选中。右列回到「请先点击画布内组件」。
- 不把这次切换记成未保存。频道本身没被改。

切换底部导航入口，同样取消选中。新入口若是功能页面，画板整个不显示。

手机预览顶部的频道名只展示当前入口有哪些频道，点它们不能切换。

### 4.4 保存、发布、离开

页顶红字：「编辑完成后请先保存，再点击发布，APP 才会展示最新配置」。这里的 APP 在本期指 Android、iOS、H5，不包括 Web。

1. 点「保存」。先校验导航入口名称和域名 ID。通过后再逐个入口、逐个频道校验广告组件。
2. 某个广告组件不通过：停在那个入口；若它是产品页面，再切到那个频道并选中那个组件，右侧打开它的表单。提示带组件名称，例如「图标广告：请填写最多展示条数」。不写入已保存版本，发布仍不可用。
3. 全部通过：提示「已保存，请再点击发布」。发布按钮可点。
4. 保存之后再改任何一个广告字段、再拖入或再移除，发布按钮重新不可用，必须再保存一次。
5. 点「发布」后，Android、iOS、H5 才读取这份频道配置。只保存不发布，三端仍用上一份已发布内容。
6. 未保存就离开底部导航：确认后丢掉未保存的修改，回到上次保存的内容。已保存但未发布的内容还在。
7. 「恢复至上一个发布版本」会清空当前编辑，草稿回到已发布内容，并取消组件选中。已保存未发布的修改一并丢掉。

页顶「预览」只预览底部导航入口，不预览频道里的广告组件。广告长什么样，看中间手机预览。该预览是占位块，不请求广告平台。

## 5. 共用字段

每个广告组件都有广告位标识。

| 项 | 值 |
| --- | --- |
| 界面 | 广告位标识 |
| 参数 | `adSlotKey` |
| 控件 | 单行文本 |
| 必填 | 是 |
| 占位 | 请输入广告平台中广告位的广告位标识字段 |
| 说明 | 广告平台里该广告位的固定标识。组件用它拉取素材。两个组件填同一个值，请求同一个广告位 |

空字符串不能保存。提示「请填写广告位标识」，并带上组件名称。

## 6. 分组件字段

下面每个组件的保存结果都包含 `componentType` 和 `adSlotKey`。未列出的键不保存。

### 6.1 Banner 广告

对应 `BannerAdWidget.fromSlot`。

| 界面 | 参数 | 控件 | 必填 | 默认 | 说明 |
| --- | --- | --- | --- | --- | --- |
| 广告形式 | `format` | 单选：普通 Banner、大 Banner | 是 | 普通 Banner | 普通为 `banner`，即 `AdFormat.banner`。大为 `bannerLarge`，即 `AdFormat.bannerLarge` |
| 展示宽度 | `size.width` | 正整数，可空 | 否 | 空 | 与高度成对 |
| 展示高度 | `size.height` | 正整数，可空 | 否 | 空 | 与宽度成对 |
| 多条间距 | `itemSpacing` | 非负整数，单位 px | 否 | 12 | 该广告位返回多条并纵向排列时，条与条的间距。SDK 没有轮播个数和停留秒数 |

校验：

- 宽度和高度都空：不传 `size`，使用广告位下发的尺寸。
- 只填一边：不允许保存。提示「展示宽度和高度需要同时填写」。
- 填了的一边必须是正整数。
- 间距空则保存为 12。填了则必须是非负整数。

`format` 必传。不传 `placement`。位置就是组件在频道中的顺序。

### 6.2 图标广告

对应 `IconAdWidget.fromSlot`。默认布局为自动。

| 界面 | 参数 | 控件 | 必填 | 默认 | 说明 |
| --- | --- | --- | --- | --- | --- |
| 布局 | `layout` | 单选，见下表 | 是 | 自动 | 决定这一组图标怎么排 |
| 最多展示条数 | `maxCount` | 见显隐表 | 条件 | 不限制 | 宫格时改为必填正整数 |
| 列数 | `columns` | 正整数 | 条件 | 5 | 一行几个。横向和轮播不使用 |
| 间距 | `spacing` | 非负整数，单位 px | 条件 | 8 | 图标之间的间距。单图和轮播不使用 |
| 图标尺寸 | `style.size` | 正整数，单位 px，可空 | 否 | 空 | 空则不传 `IconAdStyle.size`，用 SDK 默认尺寸 |

布局、气泡和端上行为：

| 界面 | 值 | 悬停说明 | 端上行为 |
| --- | --- | --- | --- |
| 自动 | `auto` | 广告位只返回 1 条时显示单图，返回多条时按宫格排列 | `IconAdLayout.auto`。一条单图，多条宫格 |
| 单图 | `image` | 只显示第一条素材 | `IconAdLayout.image`。只展示首条 |
| 宫格 | `grid` | 按列数排成宫格，标题使用素材标题 | `IconAdLayout.grid`。标题用 `creative.title` |
| 横向滚动 | `horizontal` | 单行横向滑动，不使用列数 | `IconAdLayout.horizontal`。忽略 `columns` |
| 单图标轮播 | `carousel` | 每页一个图标，不显示标题。可以左右滑动，约每 3 秒自动切换 | `IconAdLayout.carousel`。不展示标题。间隔由 SDK 固定，后台不配置 |

字段显隐：

| 布局 | 最多展示条数 | 列数 | 间距 | 图标尺寸 |
| --- | --- | --- | --- | --- |
| 自动 | 显示，可选不限制 | 显示 | 显示 | 显示 |
| 单图 | 隐藏。保存时写 1 | 隐藏，不传 | 隐藏，不传 | 显示 |
| 宫格 | 显示，必填 | 显示 | 显示 | 显示 |
| 横向滚动 | 显示，可选不限制 | 隐藏，不传 | 显示 | 显示 |
| 单图标轮播 | 显示，可选不限制 | 隐藏，不传 | 隐藏，不传 | 显示 |

非宫格的「最多展示条数」：

- 提供「不限制」和「指定条数」。
- 不限制保存为 `0`。
- 指定条数未填不能保存。填了必须是非负整数。

宫格的「最多展示条数」：

- 标签为「最多展示条数 *」。没有「不限制」。
- 必须填写正整数。空或 0 不能保存，提示「请填写最多展示条数」。
- 字段下方固定文案：「最大值不要超过列数*3」。
- 保存时用列数计算上限。列数空则按默认 5。条数大于列数 × 3 时不能保存，提示「最多展示条数不要超过列数的 3 倍」。列数为 5 时最大 15，列数为 4 时最大 12。

列数、间距、图标尺寸：

- 列数空则按该布局的默认值保存。填 0 或非正整数不能保存。
- 间距空则保存为 8。填了必须是非负整数。
- 图标尺寸空则保存为 `null`，端上不传 `IconAdStyle.size`。填了必须是正整数。

后台预览只作用于图标广告，随填写值重排，不请求素材：

- 宫格和自动：画出「最多展示条数」个占位图标；未填条数时按列数画一行。按列数换行。间距用填写的 px；空则按 8。
- 横向滚动：单行，个数用填写条数；未填时画 5 个。间距生效。不使用列数。
- 单图和单图标轮播：只画 1 个图标。轮播不画标题。

关闭按钮由 SDK 绘制，后台不配置。点关闭会关掉整组图标。横向列表为当前展示的各条分别上报关闭。轮播只上报当前这一条，并隐藏整个轮播。轮播约每 3 秒切换，进入后台暂停，回到前台后再等 3 秒。这些间隔不出现在表单里。

### 6.3 文字广告

对应 `TextAdWidget.fromSlot`。默认布局为单条。文字广告不套用第 6.2 节的宫格必填、悬停气泡和预览重排。

| 界面 | 参数 | 控件 | 必填 | 默认 | 说明 |
| --- | --- | --- | --- | --- | --- |
| 布局 | `layout` | 单选，见下表 | 是 | 单条 | 决定文字怎么排 |
| 最多展示条数 | `maxCount` | 非负整数，可选择不限制 | 条件 | 不限制 | 只在宫格出现。`0` 表示不限制 |
| 列数 | `columns` | 正整数 | 条件 | 3 | 只在宫格出现 |
| 间距 | `spacing` | 非负整数，单位 px | 条件 | 8 | 只在宫格出现 |
| 最大行数 | `maxLines` | 正整数 | 条件 | 2 | 标题和描述最多几行。单条和宫格出现 |

| 界面 | 值 | 端上行为 | 出现的字段 |
| --- | --- | --- | --- |
| 单条 | `cell` | `TextAdLayout.cell`，一条文字 | 最大行数 |
| 宫格 | `grid` | `TextAdLayout.grid`，按列排列 | 最多展示条数、列数、间距、最大行数 |
| 跑马灯 | `marquee` | `TextAdLayout.marquee`，横向滚动 | 无。速度用广告位 `display_rule.scroll_speed` |

宫格的条数可以选择不限制。指定条数未填不能保存。不要求「不超过列数 × 3」。列数空则保存为 3，间距空则保存为 8，最大行数空则保存为 2。跑马灯不保存条数、列数、间距和最大行数。

后台预览是固定示意：单条一条、宫格一行、跑马灯一条横条。不按填写值重排。

### 6.4 MREC 广告

对应 `MrecAdWidget.fromSlot`。没有条数、列数、布局和轮播。

| 界面 | 参数 | 控件 | 必填 | 默认 | 说明 |
| --- | --- | --- | --- | --- | --- |
| 展示宽度 | `size.width` | 正整数 | 否 | 300 | 空则保存为 300 |
| 展示高度 | `size.height` | 正整数 | 否 | 250 | 空则保存为 250 |

端上始终传 `size`。运营未改时为 `AdSize(300, 250)`。填了的值必须是正整数。

### 6.5 原生广告

对应 `NativeAdCard.fromSlot`。一张或一组带标题、描述、按钮的卡片。

| 界面 | 参数 | 控件 | 必填 | 默认 | 说明 |
| --- | --- | --- | --- | --- | --- |
| 布局 | `layout` | 单选：列表、宫格 | 是 | 列表 | 列表为 `bannerList`，即 `NativeAdLayout.bannerList`。宫格为 `grid`，即 `NativeAdLayout.grid` |
| 列数 | `columns` | 正整数，可空 | 否 | 空 | 空则不传 |

列数为空时，SDK 在列表按 1 列、宫格按 2 列。填了必须是正整数，并传 `columns`。

关闭按钮不在后台配置。广告位 `display_rule.show_close_button=true` 时，SDK 才显示关闭按钮。点击后隐藏当前卡片并上报 `ad_close`。

## 7. 端上读取约定

Android、iOS 只调用对应 Widget 的 `fromSlot`，把 `adSlotKey` 原样传入。H5 按下列字段做等价渲染，不增加配置项。

保存示例：

```json
{
  "componentType": "iconAd",
  "adSlotKey": "home_icons",
  "layout": "grid",
  "maxCount": 10,
  "columns": 5,
  "spacing": 8,
  "iconSize": null
}
```

分类型传参：

| 类型 | 调用 | 传参 |
| --- | --- | --- |
| `bannerAd` | `BannerAdWidget.fromSlot` | `adSlotKey`、`format`、`itemSpacing`。宽高都有值时传 `size`，否则不传 |
| `iconAd` | `IconAdWidget.fromSlot` | `adSlotKey`、`layout`。按第 6.2 节显隐表传 `maxCount`、`columns`、`spacing`。`iconSize` 有值时传 `IconAdStyle.size`，否则不传 |
| `textAd` | `TextAdWidget.fromSlot` | `adSlotKey`、`layout`。宫格再传 `maxCount`、`columns`、`spacing`、`maxLines`。单条只再传 `maxLines`。跑马灯不传这四项 |
| `mrecAd` | `MrecAdWidget.fromSlot` | `adSlotKey` 和 `size`。尺寸始终传递 |
| `nativeAd` | `NativeAdCard.fromSlot` | `adSlotKey`、`layout`。列数有值才传 `columns` |

单图图标传 `maxCount = 1`，不传 `columns` 和 `spacing`。

Web 桌面端忽略 `componentType` 为这五个值的组件：不占位、不请求 `adSlotKey`、不报这些组件的曝光。

加载失败、曝光、点击由 SDK 或 H5 等价埋点处理，不由运营配置回调。

## 8. 不要放进组件表单的参数

| 参数 | 原因 |
| --- | --- |
| `fromAd` / `fromAds`、`adData`、`ads` | 统一走 `fromSlot`。素材由广告位返回 |
| `dataSource`、`imageLoader`、`builder`、`onFailed`、`onImpression`、`onClicked` | 接入和埋点，不是运营配置 |
| `placement` | 位置由拖放顺序决定 |
| `onClosed`、`closeButtonWidget`、`closeButtonBuilder`、`preferenceStore` | 关闭按钮和关闭记录由 SDK 默认处理 |
| `adLabelTheme`、`adLabelBuilder` | 「广告」角标用应用级配置，不在单个组件上选明暗 |
| `BannerAdStyle`、图标圆角、文字字号、原生内边距 | 默认样式留在客户端。尺寸只保留本文已列字段 |
| 图标轮播的 3 秒间隔 | SDK 固定 |
| 文字跑马灯速度 | 广告位字段 `display_rule.scroll_speed` |
| 原生关闭按钮开关 | 广告位字段 `display_rule.show_close_button` |
| 轮播数量、轮播停留时间、1 到 5 个展示位 | 与 Widget 参数不一致，删除 |
| Web 专用尺寸或布局 | 本期不适配 Web |

开屏仍用 `SplashAd.preload` / `show`，不进入本组件分类。

## 9. 验收

| 编号 | 步骤 | 期望 |
| --- | --- | --- |
| AC-01 | 在 Android、iOS、H5 打开已发布且含五个广告组件的频道 | 五个组件按保存字段渲染，广告位标识与后台一致 |
| AC-02 | 在 Web 桌面端打开同一频道 | 不展示这五个组件，不请求它们的广告位 |
| AC-03 | 广告位标识留空后保存 | 不能保存，提示请填写广告位标识。标识 `Home_Ad` 保存后仍是 `Home_Ad` |
| AC-04 | Banner 只填宽度，或宽高都空 | 只填一边不能保存。都空时端上不传 `size` |
| AC-05 | 图标布局选宫格，条数空，或条数大于列数 × 3 | 不能保存。列数 5 时 15 可保存，16 不可保存 |
| AC-06 | 图标布局选宫格，条数 10、列数 5、间距 8 | 后台预览为两行、一行 5 个、间距 8px。端上按宫格渲染，标题用素材标题 |
| AC-07 | 悬停图标广告的五个布局 | 各自出现第 6.2 节的气泡。文字广告的布局没有气泡 |
| AC-08 | 图标布局选单图后保存 | `maxCount` 为 1，配置中没有列数和间距 |
| AC-09 | 图标布局选自动或不限制 | `maxCount` 为 0。返回素材更少时只展示返回条数 |
| AC-10 | 文字广告选宫格并选择不限制 | 可以保存，`maxCount` 为 0。不要求不超过列数 × 3。预览不按条数重排 |
| AC-11 | 文字广告选跑马灯 | 不保存条数、列数、间距、最大行数。速度来自广告位，后台没有速度输入框 |
| AC-12 | MREC 宽高留空后保存 | 保存为 300 和 250，端上传 `AdSize(300, 250)` |
| AC-13 | 原生广告列数留空 | 不传 `columns`。列表按 1 列，宫格按 2 列 |
| AC-14 | 同一广告位标识拖入两个组件 | 两端请求同一个广告位 |
| AC-15 | 只保存、不发布 | Android、iOS、H5 仍显示上一份已发布配置 |
| AC-16 | 单击左侧广告卡片，不拖动 | 画布不新增组件 |
| AC-17 | 把图标广告拖进手机搜索条区域，再拖一次 | 当前频道末尾依次出现两份实例。选中第二份时，只改第二份的表单 |
| AC-18 | 选中组件后点右侧另一个频道 | 预览换成该频道的组件，右列回到「请先点击画布内组件」，页面不因此变成未保存 |
| AC-19 | 选中图标广告，把布局改成宫格，再悬停「宫格」 | 条数字段变为必填且没有「不限制」。气泡为第 6.2 节文案，移开后消失 |
| AC-20 | 保存时第二个频道上的 Banner 未填广告位标识 | 自动切到该频道并选中该 Banner，发布仍不可用 |
