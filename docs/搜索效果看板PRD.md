## 1. 背景与目标

### 1.1 背景

搜索效果依赖埋点与数仓日表。运营需要在一个页面里同时看到：

1. 搜索量与点击是否健康（整体 KPI + 趋势）
2. 有结果 / 无结果供给是否恶化（堆叠柱）
3. 哪些词「高搜低点击」（热搜词效果榜）
4. 哪些词「有搜无货」，补货后有没有改善（无结果词榜 + 30 日趋势）

### 1.2 目标

- 提供 **T+1 日表** 的搜索效果看板，不接实时流。
- 页级筛选：时间范围（预设 + 起止日）+ 内容类型。
- 页面一次性展示 KPI、两张图、两张明细表、口径说明，无需子页。
- 词行可展开查看该词近 30 个已就绪统计日的趋势，用于追踪效果和补货。

### 1.3 非目标

- 不做实时大盘、不做分钟级刷新。
- 本页不提供改词、补货、配置搜索策略的写操作（只读分析）。
- 搜索词归一化、脏词清洗由数仓完成，前端不清洗。


### 3.1 页头

### 3.2 数据可用性告警条

> 「无结果率」「无结果次数」及词榜供给相关列依赖 **search_result_count** 字段，该字段当前存在「有结果上报为 0」的问题，开发修复中；修复版本上线前相关数据不可用，趋势自修复覆盖日起算。「点击率」依赖 search_trace_id 关联，待空串率摸底验证。

## 4. 查询条件（页级）

筛选栏无单独「查询」按钮。任一页级条件变更后 **立即重新请求** KPI、两张图、表 1（表 2 默认跟随，除非用户已改过表 2 独立时间，见 §8.3）。日期控件 `change` 即查询；内容类型 `change` 即查询。

### 4.1 字段一览

| 控件 | 类型 | 必填 | 默认 | 作用 |
| --- | --- | --- | --- | --- |
| 时间预设 | 下拉 | 是 | 近7天 | 一键填入开始/结束时间 |
| 开始时间 | 日期，精确到日 | 是 | 近7天的起始日 | 统计闭区间左端 |
| 结束时间 | 日期，精确到日 | 是 | 昨天（最新就绪日） | 统计闭区间右端 |
| 内容类型 | 下拉 | 是 | 全部 | 过滤搜索发生的内容形态 |

时间预设选项（顺序固定）：

1. 昨天
2. 近7天
3. 近15天
4. 近30天
5. `-`（自定义占位，不是「本周/上周」）

内容类型选项：`全部` / `视频` / `小说` / `漫画`。

### 4.2 数据日与「当天不可查」

定义：

- **自然日**：业务时区东八区，日切 `00:00:00`。
- **今天** `T`：打开页面时的业务自然日。
- **最新就绪日** `D = T - 1 天`：T+1 数仓已产出的最近一天。**今天及未来日期一律不可查。**

日期控件：

- `max` 绑定为 `D`，日期面板里当天、明天不可点。
- 若用户通过粘贴 / 接口拿到 `> D` 的日期：前端截断为 `D`，再查询。
- 开始时间 `> ` 结束时间：把开始时间改成结束时间，再匹配预设。
- 开始、结束均为闭区间，包含两端日期。例如近 7 天包含 `D` 当天。

### 4.3 预设如何换算起止日

一律相对 **最新就绪日 D**，**不含今天**。

| 预设 | 开始时间 | 结束时间 | 含天数 |
| --- | --- | --- | --- |
| 昨天 | D | D | 1 |
| 近7天 | D − 6 天 | D | 7 |
| 近15天 | D − 14 天 | D | 15 |
| 近30天 | D − 29 天 | D | 30 |
| `-` | 不改当前起止 | 不改当前起止 | — |

例：今天 2026-09-28，则 D = 2026-09-27。默认近 7 天 = `[2026-09-21, 2026-09-27]`。

### 4.4 预设与起止日的联动（非强制绑定）

**改预设 → 改日期**

- 选昨天 / 近7 / 近15 / 近30：立即写入对应起止日并查询。
- 选 `-`：**不改**起止日、不强制查询（若日期未变则无需请求）。用于用户先改日期、预设已被置为 `-` 后的展示态。

**改开始或结束时间 → 改预设**

改完后先做 §4.2 截断，再按下表回写预设（**精确匹配**，必须结束日 = D 才算命中近 N 天 / 昨天）：

| 条件 | 预设显示 |
| --- | --- |
| start = D 且 end = D | 昨天 |
| end = D 且 start = D−6 | 近7天 |
| end = D 且 start = D−14 | 近15天 |
| end = D 且 start = D−29 | 近30天 |
| 其它任意区间（含结束日不是昨天、天数碰巧为 7 但结束日偏了） | `-` |

要点：近 7 天不是「任意连续 7 天」，必须是 **以昨天为右端的滚动 7 天**。用户把结束日改成前天、开始日仍差 6 天，预设为 `-`。

### 4.5 内容类型

| 值 | 口径 |
| --- | --- |
| 全部 | 不限内容形态，KPI / 图 / 表按全部搜索事件汇总 |
| 视频 / 小说 / 漫画 | 仅该形态下的搜索（与埋点内容类型字段对齐，由数仓映射） |

热搜表中的「点击视频 / 点击小说 / 点击漫画」是 **结果点击分类型计数**，即使页级筛了「视频」，这三列仍展示（视频列会占主导，其它类型可为 0）。不要因为筛了视频就藏掉小说、漫画列。

### 4.6 查询校验与提示

| 场景 | 行为 |
| --- | --- |
| 开始或结束为空 | 不允许提交；控件保持上次合法值 |
| 区间跨度 | 建议上限 90 个统计日；超过 toast「时间范围不能超过 90 天」并拒绝请求 |
| 无数据 | KPI 显示 `—`，图空态「所选时间内暂无数据」，表空态同样文案 |
| 接口失败 | 模块内错误条 + 重试，不整页白屏 |
| 加载中 | KPI / 图 / 表骨架或 loading，避免旧数与新筛选项错位 |

## 5. 指标口径（数仓 / 接口必须一致）

事件与字段以数仓为准，前端不做二次口径发明。下列为产品定义。

一次「搜索」用 `search_trace_id` 归并。同一 trace 下多次点击计 **1 次有点击搜索**。点击率封顶 100%。

访客键与一级类目消费看板对齐：`COALESCE(uid, device_id)`（若搜索侧另有约定，在接口文档写死，本页 UV 必须与之一致）。

### 5.1 搜索 PV

- 定义：筛选区间内 `keyword_search` 触发次数。
- 展示：大数可用「万次」，保留 1 位小数；小于 1 万用千分位整数。
- 附注：keyword_search 触发次数。

### 5.2 搜索 UV

- 定义：筛选区间内发起过搜索的去重访客。
- 附注：发起搜索的去重用户。

### 5.3 搜索点击率（次数口径，主指标）

```
有点击的搜索次数 / 搜索总次数
```

- 按 `search_trace_id` 归并：一次搜索内点多次只计 1。
- 用于词效果、热搜表「点击率」列。
- **禁止**用「趋势图上的点击 PV ÷ 搜索 PV」代替本指标（两线量纲不同，且点击 PV 是结果点击次数，不是「有点击的搜索次数」）。
- 图例必须出现提示：点击率勿用两线相除，见顶部卡片口径。

### 5.4 搜索用户点击率（UV 口径）

```
搜索后产生过点击的去重访客 / 发起搜索的去重访客
```

衡量搜索功能整体健康度，不进词表。

### 5.5 无结果率

```
search_result_count = 0 的搜索次数 / 搜索总次数
```

与点击率同分母，漏斗为：无结果 → 有结果零点击 → 有点击。

KPI 在无结果率偏高时用警示色（原型为红字）。建议：无结果率 ≥ 10% 用警示色。阈值可配置。

### 5.6 有结果 / 无结果搜索次数（供给图）

- 无结果次数：`search_result_count = 0` 的搜索次数。
- 有结果次数：搜索 PV − 无结果次数（或 `search_result_count > 0`）。
- 每日柱总高 = 当日搜索 PV。
- 当日无结果率 = 当日无结果次数 / 当日搜索 PV，用于柱子 hover。

### 5.7 结果点击分类型（热搜表）

一次搜索结果点击记入视频 / 小说 / 漫画之一（按点击内容类型）。列为次数，不是 UV。

## 6. KPI 卡片

5 张，从左到右固定：

| 顺序 | 名称 | 主数值 | 单位示例 | 下方说明 |
| --- | --- | --- | --- | --- |
| 1 | 搜索 PV | §5.1 | 万次 / 次 | keyword_search 触发次数 |
| 2 | 搜索 UV | §5.2 | 万人 / 人 | 发起搜索的去重用户 |
| 3 | 搜索点击率 | §5.3 | %，1 位小数 | 次数口径：有点击的搜索次数 ÷ 搜索次数 |
| 4 | 搜索用户点击率 | §5.4 | %，1 位小数 | UV 口径：搜索后点击 UV ÷ 搜索 UV |
| 5 | 无结果率 | §5.5 | %，1 位小数 | result_count=0 的搜索次数占比；未修复时说明「待修复」 |

分母为 0：主数值显示 `—`，不显示 0% 或 Infinity。

无点击率、无结果率相关告警时，卡片说明行可跟一句「口径待验证」，不挡数字。

## 7. 图表

两张并排。横轴为筛选区间内每一个统计日（缺数日补空心点或断线，不要把日期挤掉）。区间 > 15 天时横轴抽稀标签，首尾必须标出。

### 7.1 搜索与点击趋势

- 类型：双线双轴折线。
- 左轴：搜索 PV（蓝实线 + 圆点）。
- 右轴：点击 PV（绿虚线 + 圆点）。点击 PV = 结果点击次数，**不是**有点击搜索次数。
- 标题旁副文案随筛选变化，例如「2026-09-21 ~ 2026-09-27 · 双线双轴（左：搜索PV，右：点击PV）」。
- Hover：日期、搜索 PV、点击 PV。不要在 hover 里用两线相除当点击率。
- 图例三项：搜索 PV（左轴）；点击 PV（右轴）；灰色注释「点击率勿用两线相除，见顶部卡片口径」。

### 7.2 搜索结果供给情况

- 类型：堆叠柱。下段绿 = 有结果搜索次数，上段红 = 无结果搜索次数。
- 副文案：筛选区间 +「修复后无结果段应下降」。
- Hover：日期、有结果次数、无结果次数、当日无结果率。
- 图例：有结果搜索次数；无结果搜索次数；灰字「悬浮显示当日无结果率」。
- `search_result_count` 不可用的日期：柱子灰显或打点「不可用」，hover 说明原因。

## 8. 表格

### 8.1 通用交互

| 项 | 规则 |
| --- | --- |
| 排序 | 默认：日期倒序，同一日按主指标倒序。表头带 ↕ 的列可点排序；再次点击切换升/降；取消则回到默认。 |
| 主指标 | 表 1 = 搜索 PV；表 2 = 无结果次数 |
| 滚动 | 表体最高约 560px，横向可滚，表头 sticky |
| 数字 | 千分位；比率为 %，1 位小数 |
| 日期列 | `MM-DD 周X`（如 `09-01 周二`），完整日期放 title 或接口原值 `YYYY-MM-DD` |
| 展开 | 仅带 ▼ 的词行可点。点开后在该行下方插入整行明细。同一张表同时只展开一行（手风琴）：展开新行时收起旧行。再点已展开行则收起。 |
| 展开范围 | 每一个统计日的 TOP 词均可展开（原型只做了最新一天，正式环境不要限制在最新一天）。 |
| 趋势窗口 | 以 **该行日期为结束日**，往前共 30 个统计日（含该行日期，仍不含「今天」）。不受页级 7/15 天筛选截断。 |
| 空趋势 | 展示「暂无足够历史」 |
| 加载 | 展开时可先出 loading，再画趋势，避免卡住整表 |

点击率 / 无结果率色标（正式环境用固定阈值，不要按原型示意个案硬编码）：

**点击率（表 1）**

| 区间 | 样式 |
| --- | --- |
| ≥ 18% | 绿 |
| 10%（含）~ 18% | 橙 |
| < 10% | 红 |

**无结果率（表 2）**

| 区间 | 样式 |
| --- | --- |
| ≥ 50% | 红 |
| 20%（含）~ 50% | 橙 |
| < 20% | 绿 |

缺口类型始终灰底标签，文案见 §8.3。

### 8.2 表 1：热搜词效果榜 · 每日明细

**目的**：日期 × 归一化搜索词，每天按搜索 PV 取 TOP，找高搜低点击。

**数据范围**：跟随页级开始/结束时间、内容类型。

**每日条数**：默认每天 TOP 5（可配置 `top_n`，默认 5）。PV 并列按 UV、词名字典序打破并列。

**列**

| 列 | 来源 / 计算 | 对齐 |
| --- | --- | --- |
| 日期 | 统计日 | 左 |
| 搜索词 | 数仓归一化后的词；可展开行在词旁显示 ▼ | 左 |
| 搜索 UV | 该日该词搜索去重访客 | 右，可排序 |
| 搜索 PV | 该日该词搜索次数 | 右，可排序，默认同日按此倒序 |
| 点击率 | §5.3，仅该日该词 | 右，可排序，色标 |
| 点击视频 | 该日该词点到视频的次数 | 右 |
| 点击小说 | 同上，小说 | 右 |
| 点击漫画 | 同上，漫画 | 右 |

**展开**：标题「「{词}」近 30 天点击率趋势」。折线 Y 轴为点击率 %。用于判断高搜低点击是单日还是长期（如「赘婿」长期 5%~7%）。

表上说明文案：

> 日期倒序、同日按搜索 PV 倒序，每日展示 TOP5 · 带 ▼ 的词行可点击展开近 30 天点击率趋势

### 8.3 表 2：无结果搜索词 · 每日供给缺口追踪

**目的**：按无结果次数（受影响人次）找供给缺口，并用 30 日无结果次数看补货是否见效。

**纳入条件**：该日该词 **搜索 PV ≥ 150** 才进榜。阈值可配置，默认 150。

**每日条数**：每天 TOP 5，按无结果次数倒序。

**页级筛选 vs 本表时间**

- 内容类型：始终跟页级。
- 时间：表头提供「本表时间范围」下拉，选项与页级预设相同（昨天 / 近7天 / 近15天 / 近30天 / `-`）。
- **默认**：进入页面或用户只改页级时间且从未改过本表下拉时，本表时间 = 页级时间。
- **解绑**：用户改过本表下拉后，本表时间独立；再改页级时间 **不再覆盖** 本表（避免运营对比「大盘近 7 天、缺口近 30 天」时被冲掉）。提供「跟随页面时间」文字按钮可一键重新绑定（若实现成本高，第一期可省略按钮，刷新页面恢复跟随）。
- 本表选 `-`：不改本表当前起止（若本表没有独立起止，则继续用页级起止，仅把本表下拉显示为 `-`）。
- 本表选昨天 / 近 N 天：按 §4.3 相对 D 计算，只刷新表 2。

## 9. 页脚口径说明（固定展示）

与原型一致，上线后把最后一句改成「数据由数仓日表产出，T+1 可查」：

- **搜索点击率**（次数口径，主指标）：发生过点击的搜索次数 ÷ 搜索总次数；按 search_trace_id 归并，一次搜索内多次点击只计 1 次，封顶 100%。用于词维度效果评估。
- **搜索用户点击率**（UV 口径）：搜索后产生点击的去重用户 ÷ 发起搜索的去重用户；衡量搜索功能整体健康度。
- **无结果率**：search_result_count = 0 的搜索次数 ÷ 搜索总次数。与点击率同分母，构成「无结果 → 有结果零点击 → 有点击」漏斗。
- **热搜词效果榜**：日期 × 词粒度明细，每天按搜索 PV 倒序取 TOP，定位「高搜低点击」词；点词行可看该词近 30 天点击率趋势。
- **无结果词榜**：日期 × 词粒度明细，每天按无结果次数排序（受影响人次），用于定位供给缺口、追踪运营补货进度；搜索词归一化与脏词清洗由数仓处理。

## 10. 接口建议（给研发拆任务）

以下为逻辑合同，路径可按网关规范改。所有查询 **禁止传入今天及以后的日期**；服务端若收到 `end_date >= 今天`，按 D 截断或直接 400。

### 10.1 页级汇总 `GET /api/search-effect/overview`

Query：`start_date`、`end_date`（`YYYY-MM-DD`）、`content_type`（`all|video|novel|comic`）

返回：

- `latest_ready_date`
- `kpis`：pv、uv、ctr、user_ctr、zero_result_rate
- `trend[]`：date、search_pv、click_pv
- `supply[]`：date、search_pv、has_result_cnt、zero_result_cnt、zero_result_rate
- `warnings`：供给 / 点击率是否可用、文案、`supply_reliable_from`

### 10.2 热搜词 `GET /api/search-effect/hot-terms`

Query：同上 + `top_n`（默认 5）

返回行：date、term、search_uv、search_pv、ctr、click_video、click_novel、click_comic

排序由服务端按 §8.1 默认序排好；前端再做列排序。

### 10.3 无结果词 `GET /api/search-effect/zero-result-terms`

Query：`start_date`、`end_date`、`content_type`、`top_n`、`min_pv`（默认 150）

返回行：date、rank、term、search_uv、search_pv、zero_result_cnt、zero_result_rate、gap_type

### 10.4 词趋势 `GET /api/search-effect/term-trend`

Query：`term`、`end_date`（该行日期）、`metric`（`ctr` | `zero_result_cnt`）、`days`（默认 30）、`content_type`

返回：`points[]`：date、value  
窗口：`[end_date - (days-1), end_date]`，仍不超过 D。

### 10.5 时序

打开页：overview + hot-terms + zero-result-terms 并行。  
改页级筛选：三接口重打，收起已展开行。  
改表 2 时间：只打 zero-result-terms。  
展开行：打 term-trend。
