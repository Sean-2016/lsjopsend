# 运营后台产品需求文档（PRD）

| 项 | 内容 |
| --- | --- |
| 文档性质 | 静态可点击原型对应的产品需求说明（以当前 `FullOpsEnd` 实现为准） |
| 整理日期 | 2026-09-10 |
| 使用角色 | 运营、产品、研发对照实现 |
| 范围 | 已实现交互的页面写清字段与逻辑；未铺字段的菜单仅列目录与占位说明 |

本文不是改动清单，而是**按页面写清：这个功能是干什么的、列表有什么、新建要填什么、字段从哪来、校验是什么、点下去跳到哪、带什么数据**。

正式接接口时，除标注「原型演示」的行为外，字段含义与跳转约定应保持一致。

---

## 1. 需求背景

现网运营后台目录与部分能力需要按新信息架构重建。本仓库先用纯 HTML / CSS / JS 做出可点击静态原型，用于评审交互、字段和跨页跳转，不接真实接口、不做服务端持久化。

## 2. 需求目标

1. 左侧菜单按改后目录落地（一 / 二 / 三级），支持折叠与手风琴。
2. 打开过的叶子页用站内标签切换、关闭（至少保留一个）。
3. 下列模块可完整走通「查 / 增 / 改 / 关键跳转」：
   - 用户标签库
   - 用户圈选
   - 金币包商品管理
   - 用户信息管理
   - 金币&积分赠扣
   - 虚拟资产操作记录
   - 任务管理
4. 整站按视口自适应；表格列宽按内容收窄，允许行高不一致。

## 3. 阅读约定

- **必填**：保存/提交前必须有值。
- **来源**：运营手填 / 系统生成 / 其它模块数据 / 配置页 / 大数据口径。
- **作用**：这个字段在业务上决定什么。
- **原型演示**：当前静态页用 Toast、假数据或前端内存模拟，上线需接接口。

### 4.2 左侧菜单交互

| 行为 | 规则 |
| --- | --- |
| 默认状态 | 所有一级菜单折叠。默认打开页仍是「数据概览」，但不自动展开「数据中心」。 |
| 点击一级（有子级） | 若当前收起：展开本项，并收起其它已展开的一级菜单。若当前已展开：收起本项。 |
| 点击二级且仍有三级 | 仅展开/收起该二级，不强制收起其它二级。 |
| 点击叶子菜单 | 打开（或切到）对应站内标签；`expandMenuFor` 会展开该页路径上的祖先，并收起其它一级。 |
| 滚动 | 点击任意级菜单后，侧栏滚动位置保持不变，不跳回顶部。 |
| 未保存拦截 | 标签库抽屉、圈选人群包、金币包抽屉、用户弹窗、任务表单若有未保存更改，切换菜单/标签前弹出确认。 |

### 4.3 顶栏站内标签

- 每打开一个叶子页增加一个标签；点击标签切换页面。
- 可关闭标签；只剩一个时不能关。
- 关掉当前页时，切到右侧相邻标签，否则切到左侧。

### 4.4 布局

- `html/body` 不出现整页滚动条；主区、侧栏各自滚动。
- 弹窗打开时，背后页面滚轮不滚动（避免滚到父级）。

## 5. 用户标签库

**入口**：用户中心 → 用户标签管理 → 用户标签库

**页面目的**：维护「用户身上可被圈选引用的标签」。标签是圈选、用户信息打标、互斥规则的数据源。启用后的标签才会出现在圈选「选择标签」弹窗和用户信息「选择用户标签」弹窗中。

**页面说明文案**：创建标签并写清判定口径。启用后可在用户圈选里勾选。

### 5.1 列表

**筛选**

| 筛选项 | 类型 | 规则 |
| --- | --- | --- |
| 关键词 | 输入 | 匹配名称、内部 code、准确描述（即时过滤） |
| 状态 | 下拉 | 全部 / 草稿 / 启用 / 停用 |
| 重置 | 按钮 | 清空关键词与状态 |

**列**

| 列 | 展示 | 说明 |
| --- | --- | --- |
| 名称 | 展示名称 + 内部 code；系统标签带「系统预置」 | code 是大数据侧口径标识 |
| 准确描述 | 超长截断，悬停看全文 | 运营写的判定口径 |
| 状态 | 草稿 / 启用 / 停用 | 列表不提供状态复选框 |
| 人群包引用 | 「未被引用」或引用数量，可点 | 点开看哪些人群包用了该标签 |
| 更新 | 时间 · 操作人 | 原型为静态时间 |
| 操作 | 编辑、启用/停用 | 见下 |

**操作**

1. **新建标签**：打开右侧抽屉，空表单。
2. **编辑**：打开抽屉，返填该标签。
3. **启用 / 停用**：
   - 当前启用则按钮为「停用」，反之「启用」。
   - 确认弹窗文案与目标状态一致（启用就是启用，停用就是停用）。
   - **停用且仍被人群包引用**：二次确认：「圈选里仍引用该标签（包名列表），停用后该条件失效」。确认后才停用。
   - 停用后，圈选选择器不再列出该标签；已写进包里的条件显示为失效（标红），需运营自行替换或删除。
4. **人群包引用**：打开窄抽屉，列出引用该标签的人群包（名称 + 已启用/已停用）。点击某包 → 跳转 **用户圈选**，并选中该人群包。

### 5.2 新建 / 编辑标签

抽屉标题：新建标签 / 编辑标签。底部：取消、保存。名称、code、描述任一为空则保存禁用。

#### 字段说明

| 字段 | 必填 | 来源 | 控件 | 校验 / 限制 | 作用 |
| --- | --- | --- | --- | --- | --- |
| 展示名称 | 是 | 运营填写 | 输入框；placeholder「新用户」 | 非空。系统预置只读 | 后台各处给人看的名字（圈选勾选、用户信息标签展示） |
| 内部 code | 是 | **向大数据技术申请**的口径标识，不是运营自造 | 输入框；placeholder「向大数据同学要口径对应的 code，如 new、paid」；hint：保存后不可改 | 非空。新建可填；**编辑只读**；系统预置只读 | 与数仓/标签服务对齐的稳定 ID；圈选、互斥、累计充值/回归条件都靠 code 或名称规则识别 |
| 准确描述 | 是 | 运营根据大数据口径用中文写清判定 | 多行文本 | 非空，否则红字「描述不能为空」 | 给验收、给圈选悬停气泡看「这个标签到底怎么判」 |
| 新用户窗口（小时） | 条件必填 | 仅当 code 为 `new` 或已有 duration 参数 | 数字输入，默认 24 | 系统预置可改 | 定义「新用户」时间窗。保存时可把描述里的「N 小时」同步成新窗口值（原型行为） |
| 状态 | — | 系统 | **表单里不出现** | 新建保存后直接为「启用」 | 启用/停用只在列表操作列切换 |

**不做的字段（已明确砍掉）**

- 分类（列表筛选、新建表单都不需要分类）。
- 表单内状态复选框。

#### 系统预置 vs 自定义

第一期系统预置标签如下（**「免费老用户」已拆成「免费用户」+「老用户」两个独立标签**，付费与否、新老必须分开勾选才能组合）。

| 标签 | code | 口径 | 互斥 |
| --- | --- | --- | --- |
| 新用户 | `new` | 注册成功起未满 N 小时（窗口可改）。**不含**付费/免费判定 | 与老用户互斥 |
| 老用户 | `old` | 已过新用户窗口。**不含**付费/免费判定 | 与新用户互斥 |
| 付费用户 | `paid` | 至少 1 笔充值成功入账（不含 pending、不含赠币） | 与免费用户互斥 |
| 免费用户 | `free` | 从未成功充值 | 与付费用户互斥 |
| 回归用户 | `returning` | 连续 N 天无登录且无充值后再次打开 | **不互斥**，可与新/老、付费/免费组合 |
| 客户端 iOS / 安卓 / Web / PWA | `client_*` | 当前客户端类型 | **不互斥**，可多选 |
| 订阅中 | `sub_active` | 订阅在有效期中 | 与订阅失效互斥 |
| 订阅失效 | `sub_expired` | 曾经订阅过，但当前已过期 | 与订阅中互斥 |
| 有续订 | `sub_renewed` | 任意续订过一次 | **不互斥**（可与订阅中或订阅失效同时存在） |
| 安全模式开启 | `privacy_sfw_on` | 用户已开启安全模式 | 不互斥 |

圈选里要表达原来的「免费老用户」，应同时勾选 **免费用户** 与 **老用户**，并把包含区设为 AND。

| 规则 | 系统预置 | 运营新建 |
| --- | --- | --- |
| 名称、code | 不可改 | 名称可改；code 保存后不可改 |
| 描述、新用户窗口 | 可改 | 可改 |
| 抽屉提示 | 「系统预置，名称和 code 不可改，描述和窗口参数可改。」 | 无此条 |

#### 保存逻辑（原型）

- 新建：插入列表顶部，id = code，status = enabled，system = false，操作人「运营小王」。
- 编辑：只更新名称（非系统）、描述、params；code 不变。
- 成功 Toast「保存成功」，关闭抽屉。

### 5.3 标签作为其它模块的数据源

| 下游 | 怎么用标签 |
| --- | --- |
| 用户圈选 | 仅 **启用** 标签可被勾选；互斥见下表 |
| 用户信息管理 | 创建/编辑用户时选择启用标签，展示名称 |
| 互斥（三对） | ① 新用户 ↔ 老用户 ② 付费用户 ↔ 免费用户 ③ 订阅中 ↔ 订阅失效。回归、有续订、客户端不互斥 |

## 6. 用户圈选

**入口**：用户中心 → 用户标签管理 → 用户圈选

**页面目的**：**只做人群圈选**，不管被活动、广告、金币包、任务谁调用。其它业务通过「选人群包 ID」来引用。本页不维护调用方列表的业务逻辑（列表上仅展示绑定次数的展示字段）。

布局：左侧人群包列表，右侧编辑当前包。

### 6.1 左侧列表

| 元素 | 规则 |
| --- | --- |
| 搜索 | 按包名过滤 |
| 新建人群包 | 在列表顶部插入「未命名人群包」，默认 **未启用**，包含模式 OR，无标签、无国家。自动选中并进入编辑 |
| 列表项 | 名称、已启用/已停用、引用次数或「未被绑定」、更新时间 |
| 切换包 | 若当前包有未保存更改，先确认是否离开 |

### 6.2 右侧：包信息

右上角 **启用开关**（开=已启用，关=未启用）。

停用规则：

- **已经引用该包的业务可以继续使用**（例如某金币包、某任务在停用前已勾选该包：不停强制解绑，商品/任务仍按原引用生效）。
- **新业务不能引用已停用的人群包**：金币包「选择用户群」、任务「选择人群」等选择器只列出 **已启用** 的包；若当前这条业务 **已经引用** 了某个现已停用的包，该包仍会出现在选择器里（带「已停用」），只允许取消引用，不允许其它尚未引用它的业务再勾选。
- 原型不自动把已绑定的金币包/任务清掉引用。

页面上开关下方有一句说明，与上表一致。

| 字段 | 必填 | 来源 | 作用 |
| --- | --- | --- | --- |
| 人群包名称 | 是 | 运营填写 | 金币包「特定用户群」、任务「任务受众」等处展示的名字 |
| 说明 | 否 | 运营填写 | 给配置人看这个包干什么，不参与圈选计算 |
| 内部 code | — | 系统生成（如 `seg_xxx`） | **界面不展示**。配置圈选的人不需要看大数据 code |

底部：删除（确认后删包）、保存。有未保存更改时显示「有未保存更改」。离开页/切包触发确认。

### 6.3 圈选条件

用户是否进包 =（包含区命中）且（未命中排除区任一标签）且（若选了国家则国家匹配）。

#### 包含区

| 字段 | 说明 |
| --- | --- |
| 满足方式 | **满足任意（OR）** / **同时满足（AND）**。OR：包含标签命中任一即可；AND：包含标签需同时命中 |
| 标签列表 | 可多条。每条可「查看」（跳转标签库并打开该标签编辑抽屉）、「删除」 |
| 添加标签 | 打开选择标签弹窗，写入包含区 |

#### 排除区

- 命中排除中 **任一** 标签的用户不进包。
- 添加排除标签：同一套选择弹窗，写入排除区。

#### 国家

| 项 | 规则 |
| --- | --- |
| 来源 | 运营输入 ISO 两位码（如 US）或搜索中文名（美国），点选或回车 |
| 校验 | 必须是两位大写字母；非法提示「请输入两位 ISO 国家代码，如 US」 |
| 多选 | 以芯片展示「US 美国」，可叉掉 |
| 空 | **不限国家** |
| 作用 | 用户当前国家在列表内才进入包（与标签条件同时生效） |

#### 累计充值金额（条件字段）

- **何时出现**：包含/排除里某条标签为付费用户（code = `paid`）。
- **形态**：`最小 < 累计金额 ≤ 最大`。
- **区间语义**：**不包含最小值，包含最大值**。最小、最大都可留空表示该侧不限。
- **来源**：运营按业务填写金额；金额口径应对齐账本「成功入账累计充值」（与标签描述一致）。
- **作用**：在「付费用户」集合上再按金额切片。

#### 回归条件（条件字段）

- **何时出现**：标签为回归用户（code = `returning` 或名称「回归用户」）。
- **形态**：「N 天未活跃」；N 可自由填；快捷按钮 7 天、15 天。
- **作用**：定义回归判定的沉默天数（与标签库描述中的「连续 N 天无登录且无充值」对齐）。

### 6.4 选择标签弹窗

触发：添加标签 / 添加排除标签 / 点击已有条件进行替换。

| 规则 | 说明 |
| --- | --- |
| 数据源 | **仅启用中的标签**（标签库 status=enabled） |
| 分类 | **不展示分类** |
| 展示 | 三列网格；弹窗宽高随视口计算，可较大 |
| 勾选 | 每项前复选框，支持多选后点确定一次性写入 |
| 悬停 | 气泡展示该标签「准确描述」；若因互斥锁定，气泡改为锁定原因 |
| 滚动 | 滚轮只滚弹窗列表，不带动背后圈选页 |
| 搜索 | 按名称 / 描述（及 code）过滤 |
| 已在条件中 | 同一包含区或排除区内已占用的标签不可再选，原因「该标签已在条件中」 |
| 互斥 | **三对互斥，组与组之间不互斥**。已选一方则另一方置灰，原因「已选择「xxx」，与当前标签互斥」：① 新用户 ↔ 老用户 ② 付费用户 ↔ 免费用户 ③ 订阅中 ↔ 订阅失效 |
| 不互斥 | 回归用户、有续订、客户端 iOS/安卓/Web/PWA、安全模式。客户端可同时多选 |
| 空列表 | 「没有可选项，请先到标签库启用标签」 |
| 确定 | 写入当前包含区或排除区；取消关闭不保存本次勾选 |

### 6.5 预估与下载

| 元素 | 规则 |
| --- | --- |
| 符合条件用户数 | 只展示人数，**不展示用户明细列表** |
| 刷新预估 | 原型用标签条数估算人数（演示），正式环境应调圈选服务 |
| 用户列表下载 | 原型下载一份示例 uid CSV；正式环境按当前条件导出真实用户 |

**预估不作为对账依据。**

## 7. 金币包商品管理

**入口**：商业化 → 金币包商品管理

**页面目的**：配置客户端售卖的金币商品包：价格、角标、展示到期、对哪些用户可见。

### 7.1 列表

**筛选**：状态（上架/下架）、金币商品 ID、名称、实销定价、是否可享折扣、是否可复购。重置 / 搜索。

**列（含位序）**：勾选、金币商品 ID、名称、**位序**、金币量、展示定价、实销定价、是否折扣、是否可复购、状态、商品展示到期时间、操作人相关字段、操作「查看编辑」。

列表按 **位序升序**（数字越小越靠前）。分页区文案：「共 N 条，按位序升序」。

**批量**：勾选后上架 / 下架（原型改内存状态）。

### 7.2 金币价值配置（全局）

入口：列表右上「金币价值配置」。影响 **所有金币包的展示定价** 以及赠扣页金币预估金额。

| 字段 | 来源 | 作用 |
| --- | --- | --- |
| 金币数量 | 运营配置，默认 1000 | 与现金一起定义汇率 |
| 现金金额 | 运营配置，默认 1.00 | 与金币一起定义汇率 |
| 换算小数 | 四舍五入 / 直接舍去小数（默认舍去） | 展示定价保留两位小数时的取整 |

**兑换比例** = 金币数量 ÷ 现金金额。例如 1000 金币 = 1 元，则比例 = 1000。

**展示定价** = 该商品金币量 ÷ 兑换比例，再按取整规则保留两位。运营 **不能手改展示定价**（只读）。

改配置并保存后，列表与编辑抽屉中的展示定价全部重算。

### 7.3 创建 / 编辑金币包

抽屉。创建时位序默认 = 当前最大位序 + 1（至少为 1）。

| 字段 | 必填 | 来源 | 限制 | 作用 |

| 金币量 | 是 | 运营 | 数字 | 用户买到的金币数；也是展示定价的分子 |
| 展示定价 | 自动 | **金币量 ÷ 金币价值配置的兑换比例** | 只读 | 给用户看的「价值感」标价，不是实付 |
| 实销定价 | 是 | 运营 | 数字 | 用户实际支付价格 |
| 金币包角标 | 否 | 下拉 HOT / VIP / Free | 「无需角标」打开时禁用下拉 | 商品卡片角标文案 |
| 无需角标 | 否 | 开关 | 开则不展示角标 | 覆盖角标 |
| 是否可享受折扣 | 否 | 开关，默认是 | — | 是否参与折扣活动 |
| 是否可复购 | 否 | 开关，默认是 | — | 同一用户能否重复购买 |
| 商品展示到期时间 | 是 | 运营填写时间 | 文案由「展示期限」改为到期时间 | 到期后不再对用户展示该商品 |
| 商品展示策略 | 是 | 单选：全量 / 特定用户群 | 默认全量 | 全量=所有用户可见；特定=仅选中人群包内用户可见 |

#### 特定用户群

仅当策略 = 特定用户群时出现。

| 元素 | 规则 |
| --- | --- |
| 数据源 | **用户圈选里已启用的人群包**，不是标签。当前商品若已引用某个现已停用的包，该包仍显示并可取消，但不能给一条「还没引用过它」的新商品勾上 |

| 关联奖品 | 是 | 选择弹窗单选 | 预置奖品：金币、积分、会员天数 | 界面只显示名称 | 完成后发哪种资产 |
| 奖励数量 | 是 | 输入，默认 1 | 运营 | 非空 | 发多少（金币个/积分个/会员天，随奖品） |
| 展示策略 | 是 | 单选，默认「仅1次」 | 仅1次 / 每日1次 | — | 前台该任务曝光频次（与任务类型的进度刷新是不同概念） |

提交：上述必填都有值才写入列表。新建默认 **下线**。编辑保留原上下线状态。操作人记为当前账号，时间「刚刚」（原型）。

## 14. 非功能与原型边界

| 项 | 说明 |
| --- | --- |
| 技术形态 | 静态页，脚本顺序加载，不用 ES Module，保证本地打开 `index.html` 不为空白 |
| 预览 | Chrome 打开本地文件；开发过程不强制自动刷新浏览器 |
| 权限 | 原型不区分角色，默认「运营小王」 |
| 持久化 | 刷新浏览器后内存数据恢复为种子数据 |
| 预估人数、操作记录、赠扣结果 | 演示数据，不能当对账 |
| 自适应 | 按视口压缩表格宽度，体验优先于列宽整齐 |

## 15. 验收要点（已实现模块）

1. 标签库能新建（名称、大数据 code、描述），能启用停用，停用被引用标签有确认；圈选只能勾启用标签。
2. 圈选能配 OR/AND、排除、国家、累计充值开区间、回归天数；互斥仅为三对（新/老、付费/免费、订阅中/失效）；客户端与回归、有续订不互斥；停用人群包后旧引用仍可用、新业务选不到；只展示人数+下载。
3. 金币包有位序与自动展示定价；特定用户群来自圈选并可跳转圈选。
4. 用户更多：赠金币/积分跳转赠扣且带 ID + 资产 + 增加；赠 VIP 不跳赠扣。
5. 赠扣单笔四要素 + 金币预估；批量仅赠送说明 + 模板。
6. 操作记录有说明、不含当天的近 7 天默认、速览只加不减。
7. 任务筛选四条件、链接折行、类型下拉、受众来自圈选、延期说明、提交在右下无取消。
8. 菜单默认全折叠、一级手风琴、点击不回顶、站内标签可关可切。
