# 运营后台静态原型调整说明

运营小王 ｜ 2026年9月10日整理（覆盖 9月7日–9月10日 静态原型全部调整）

本文档按需求文档格式整理：**入口** 对应后台菜单位置，**原型图** 以当前静态页为准（打开 `index.html` 即可对照），**描述** 为相对原运营后台 / 首版原型的最终效果。同一入口下的多次迭代已合并为终态，不再按对话逐条罗列。

---

## 需求背景

现有运营后台目录、部分业务字段和交互需要按新结构重建。本仓库用纯 HTML / CSS / JS 做出可点击的静态原型，只展示页面与交互，不接真实接口；点击后的行为以评审确认的规则为准。

## 需求目标

1. 左侧菜单按「改后目录结构」落地，支持一 / 二 / 三级，可折叠。
2. 已打开页面用站内标签切换、关闭（至少保留一个）。
3. 已实现可交互页面：用户标签库、用户圈选、金币包商品、用户信息管理、金币&积分赠扣、虚拟资产操作记录、任务管理；其余菜单为占位页。
4. 整站按视口自适应；表格列宽按内容收窄，不强制各列等宽。

### 8. 增长运营 / 任务管理

| 入口 | 原型图 | 描述 |
| --- | --- | --- |
| 增长运营 > 任务管理 | 列表 | 1. 列表字段按现网任务表拼接，后续可继续加列。当前含：任务 id、名称、任务类型、任务受众、任务延期、行为目标、目标数值、任务跳转链接、关联奖品、奖励数量、展示策略、上下线、操作人、修改时间、操作。<br>2. 整站表格按视口自适应；列宽按内容压缩，不要求列宽一致。<br>3. **任务跳转链接** 过长时 **折行**，允许各行高度不一致，不挡住下一列。<br>4. 关联奖品只展示名称（如「金币」），**不展示 Currency 等内部编码**。<br>5. **筛选**（点搜索生效，重置清空）：状态（全部 / 上线 / 下线）、任务类型、奖品类型、行为目标。 |
| 任务管理 > 查看 | 只读弹窗 | 展示列表对应字段的只读详情（含类型、受众、延期、状态等）。 |
| 任务管理 > 新增 / 编辑 | 表单弹窗 | 1. 新增与编辑字段一致，编辑为返填。<br>2. 必填星号与标题同一行，如 `*任务名称`。<br>3. **任务类型** 为下拉（便于后续加类型）：周任务（每周刷新进度）、日任务（每日刷新进度）、进阶任务（每账号每任务仅一次）；选中后下方显示说明。<br>4. **任务受众**：来自用户圈选人群包；可选择；可 **查看/编辑人群** 跳转圈选。<br>5. **任务延期**：默认否；开启后：用户已开始任务但任务/活动到期时，仍可完成并领奖。<br>6. 去掉右下角 **取消**（与右上角关闭重复）；**重置** 在左，**提交** 在右下角。 |

## 工程说明（非产品交互）

- 预览：本机 Chrome 打开 `index.html`；开发过程中不再每次自动打开/刷新浏览器。
- 脚本按 `index.html` 顺序加载，不使用 `type="module"`，避免本地 file 协议空白。
- 本仓库为静态原型，筛选、提交、上下线等均为前端模拟，无服务端持久化。
